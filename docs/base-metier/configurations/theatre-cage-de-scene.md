# Configuration : théâtre à cage de scène
Version 0.1 du 18.11.2026. Niveaux : [consensus] [usage].

**Ce que le lieu offre** : cadre de scène, cintres avec de nombreuses perches (souvent des tubes, contrebalancés ou motorisés), passerelles, face en salle (passerelle ou balcon), rideaux noirs complets.
**Lumière**
- Face depuis la salle, à 45° : c'est la meilleure position de face de toutes les configurations. [consensus]
- Contres sur les perches du lointain, douches au milieu, latéraux dans les rues de pendrillons. [usage]
- Une perche de théâtre est un tube : charge répartie limitée, pas de charge lourde concentrée. [usage, voir 03]
**Son** : façade au cadre, de part et d'autre ; rappels au nez de scène ; délais sous balcon. [consensus, voir 02]
**Rigging** : la charge de chaque perche est donnée par le théâtre ; seul le personnel du lieu manœuvre les cintres. [consensus]
**Pièges** : frises et pendrillons qui coupent les faisceaux ; perches déjà prises par les tissus.
