# Style : jazz

Version 0.1 du 18.11.2026. Peu de sources pour l'instant : à étoffer. Niveaux : [consensus] [à valider].

**Formation type** : trio à quintette. Piano ou guitare, contrebasse, batterie, un ou deux soufflants, parfois chant.

**Plateau** [à valider] : groupe serré, en arc de cercle pour que les musiciens se voient. Piano à jardin, couvercle ouvert vers le public ; contrebasse au centre près de la batterie ; soufflants à la face.

**Lumière**
- La musique passe avant le spectacle. Une ambiance par morceau au plus. [consensus]
- Les musiciens restent toujours éclairés ; si quelque chose change, c'est le fond. [consensus]
- Couleurs profondes au lointain, face neutre ou couleur chair. [consensus]
- Le public veut voir les échanges entre musiciens : pas de noir sur ceux qui ne jouent pas le solo. [consensus]
- Beaucoup de contre en couleurs profondes suffit à faire l'image. [consensus]
- Fondus lents ; pas de mouvement d'automatiques visible, pas de strobe, pas d'aveuglants. [à valider]
- Dire ces consignes aux techniciens du lieu avant le montage. [consensus]

**Son**
- L'idée : un ensemble acoustique légèrement renforcé, pas une sono de rock. [consensus]
- Subs facultatifs dans une petite salle. [consensus]
- Niveau de retours faible, souvent peu de retours demandés. [à valider]
- Petit système propre plutôt que gros système poussé. [consensus]

**Vidéo** : inhabituelle.

**Séquences types** [à valider]
1. Accueil public · 2. Entrée des musiciens · 3. Ambiance chaude (tempo moyen) · 4. Ambiance froide (ballade) · 5. Ambiance vive (tempo rapide) · 6. Saluts · 7. Sortie public
