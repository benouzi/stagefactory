# Style : danse
Version 0.1 du 18.11.2026. Niveaux : [consensus] [usage].

**Plateau** : nu, tapis de danse, coulisses par rues de pendrillons, aucun obstacle au sol. [usage]
**Lumière**
- Le corps, pas le visage : les latéraux sont la source principale, à plusieurs hauteurs dans chaque rue (ras du sol, mi-hauteur, tête). [usage]
- Les latéraux donnent le relief que la face efface. [consensus, voir 01]
- Face faible ; contres et douches pour dessiner l'espace. [usage]
- Sol propre : rien de posé sur le plateau, projecteurs en coulisse. [usage]
**Son** : diffusion de bande, façade plus rappels de plateau pour les danseurs (side fills en coulisse). [usage]
**Séquences types** : Accueil · Noir · Latéraux froids · Latéraux chauds · Douche centrale · Couloir (une rue) · Plein feu · Noir · Saluts · Sortie.
